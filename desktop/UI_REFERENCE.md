# v1.1 원본 HTML 조작 방식 복원

첫 버전의 개별 입력 폼을 원본 HTML의 표·선택창·교환 흐름에 맞춰 교체했습니다. 원본 파일은 수정하지 않았습니다. Google Apps Script 호출은 로컬 React 상태와 Electron 저장으로 대체했습니다.

선택창 내부 수정은 적용 버튼을 누르기 전까지 문서에 반영되지 않습니다. 수동 배정 역시 임시 상태로 유지하다 변경사항 반영 시 독립 검증 후 문서에 적용합니다. 횟수 초과는 경고하고 금지·중복 배정은 거부합니다. 페이지 이동 시 임시 배정은 보존하며 종료 전 미반영 변경을 알립니다.

교사·고사실 이름 대신 ID로 연결하는 저장 형식은 유지했습니다. v1.0 문서를 그대로 열 수 있습니다. 제외 표의 행별 사유 보존용 선택 필드만 추가했습니다.

복합 시험과목 입력(쉼표 또는 / 구분)은 원본처럼 각 담당과목으로 나누어 해당 교시 전체에서 제외합니다. 엔진 버전은 1.0.1로 변경했습니다.

로컬 앱에서 불필요한 서버 동기화 버튼은 자동 저장과 단계 이동으로 바꿨습니다. 외형은 밝은 사이드바·얇은 테두리를 유지하되 표 구분, 글자 대비, 이름과 날짜 헤더 고정에 우선순위를 두었습니다.

## 통합 UI 검토판 (설치 패키지 생성 전)

공유된 Google Sheets의 교사별 전체 시간표를 확인한 뒤, 메뉴를 시험 설정 / 교사 설정 / 배정표 / 기록으로 통합했습니다. 시험 설정 안에서 일정·고사실과 감독 방식·배정 기준을 전환합니다. 교사 설정 안에서 명단과 가능 시간·제외 전체 표를 전환합니다.

배정표는 29px 행, 날짜별 교시 그룹, 고정 이름 열과 헤더를 사용합니다. 위쪽 중복 제목과 카드 여백을 줄이고 화면 안에서 표만 스크롤합니다. 검증 내역은 별도 대화상자로 열립니다. 고사실 설정은 접을 수 있으며 기존 과목·고사실 선택창과 같은 교시 맞교환은 유지합니다.

가능 시간·제외는 TeacherTimes.tsx에서 한 셀의 가능/불가/제외 선택으로 편집합니다. 기존 availability와 exclusions 데이터를 유지하므로 이전 저장 파일을 읽을 수 있습니다. 버튼·선택창·표의 공통 간격과 톤은 compact.css에서 정의합니다.

이 변경은 npm run dev 확인용입니다. 사용자 컨펌 전에는 설치 파일을 생성하지 않습니다.

## 가독성·명단 가져오기 수정

설정 본문과 입력은 15~16px를 기준으로 키웠고 왼쪽에 일정·고사실, 감독 방식·배정 기준, 교사 명단, 가능 시간·제외를 항상 표시합니다. 고사실 관리는 기본으로 펼쳐집니다. 선택된 항목과 주요 동작에는 #007aff 계열의 파랑을 사용하고 과목·담임·이동학급에는 파랑·민트·라벤더 칩을 사용합니다.

교사 명단은 ExcelJS로 메인 프로세스에서 읽으며, preload는 파일 선택 작업만 노출합니다. 렌더러가 임의의 경로를 지정할 수 없습니다. 추가 전에 시트·제목 행·열 매핑·행별 오류를 확인합니다. Google Sheets는 내려받은 파일 또는 복사한 표로 가져옵니다.

규칙·저장·파일 파싱 테스트 28건, 개발 빌드와 격리된 Electron 파일 가져오기 UI 검증 통과. 캡처는 test-artifacts/readable-*.png입니다. 설치 패키지는 사용자 확인 전 생성하지 않았습니다.

## iOS 컨트롤 참고 디자인 수정

공유된 Figma Community 파일의 밝은 테마 Controls/Tables(node 16:6223)를 브라우저에서 시각적으로 확인했습니다. 흰색 그룹 행, 얇은 구분선, 둥근 선택 표시와 절제된 파랑을 참고했으며 정확한 치수나 디자인 토큰을 추출한 것은 아닙니다.

디자인 레이어는 compact.css 대신 ios-controls.css를 사용합니다. 고사실 관리는 학년별 그룹 행으로 정리하고, 학급 칩의 상시 입력칸을 RoomToken 버튼과 이름 변경 대화상자로 바꿨습니다. ID는 그대로 유지합니다. 과목·학급 선택창은 체크 표시가 있는 목록으로 통일했습니다. 기존 HTML의 표·선택·적용 흐름과 파일 가져오기는 유지합니다.

npm run build 및 scripts/smoke-design.mjs로 이름 변경·취소, ID 유지, 선택 표시, 작은 창 가로 넘침과 렌더러 오류를 검증합니다. 화면 캡처는 test-artifacts/ios-*.png에 저장합니다. 설치 패키지는 사용자 확인 후 생성합니다.

## iOS 컨트롤 2차 다듬기

Figma Community iOS UI Components(Controls·Tables)의 인셋 그룹 목록, 세그먼트 컨트롤, 틴트 토큰을 더 가깝게 따랐습니다. 한글 가독성을 위해 Pretendard Variable을 로컬 번들에 포함했습니다. 인터넷 연결 없이 동작합니다.

- 사이드바: 현재 페이지를 파란색으로 채워 표시하고, 상위 그룹은 아이콘만 파랑으로 둡니다.
- 섹션 탭: 설명 문구를 뺀 iOS 세그먼트 컨트롤로 바꿨습니다.
- 고사실 관리: 섹션 제목을 카드 밖 각주로 옮기고 학년 행을 하나의 흰색 그룹 카드로 묶었습니다. 학급 칩은 학년별 틴트(1 파랑·2 초록·3 주황, 복도 인디고·특별실 청록)의 둥근 사각 토큰입니다. 연필 아이콘을 없애고 칩 전체를 눌러 이름을 바꿉니다. 삭제는 작은 원형 x 버튼입니다.
- 교사 표: 역할과 메모를 한 줄에 두어 행 높이를 줄이고, 과목·담임·이동학급 칩을 틴트로 통일했습니다.

npm run build, scripts/smoke-design.mjs, scripts/smoke.mjs, npm test(28건)를 통과했습니다.

## 가능 시간 체크박스

가능/불가/제외 드롭다운을 교시별 체크박스 하나로 바꿨습니다. 체크는 감독 가능, 해제는 감독 불가입니다. 해제하면 availability에서 빼고 exclusions에 불가 사유와 함께 기록하므로 필수배치 규칙, 배정표의 불가 사유 표시, 기존 저장 파일이 그대로 동작합니다.

## 교사 분류와 지정배치

- 분류: 일반 교사, 지정배치(구 필수배치), 시간강사, 비교과, 순회, 복도 전담, 감독 제외. 이전 파일의 `required`는 지정배치, `priority`는 시간강사로 읽습니다.
- 일반 교사: 가능 시간 표에서 체크된 교시 중 엔진이 점수를 고르게 나눠 배정합니다. 해제한 교시는 불가이며 사유를 함께 적습니다.
- 지정배치 계열(지정배치·시간강사·비교과·순회·복도 전담): 체크한 교시에만, 체크한 교시마다 반드시 배정합니다. 새로 이 분류로 바꾸면 체크가 모두 비어 있습니다. 횟수 상한과 점수 균등 계산에서는 빠집니다.
- 배치 자리(교사별): 복도 우선 / 교과 우선 / 교과·복도 모두 / 복도만. 정/부 모드에서는 부감독 우선 / 정감독 우선 / 정·부 모두 / 부감독만으로 표시합니다. 기본값은 시간강사·비교과 복도 우선, 지정배치·순회 교과·복도 모두, 복도 전담 복도만입니다.
- 복도 우선은 같은 교시 복도가 다 차거나 교과 자리가 비면 교과·정감독에 들어갑니다. 복도만은 들어가지 않고 지정배치 미충족 경고를 남깁니다(자습 교시는 예외).
- 엔진: 지정 교시를 먼저 선호 자리에 배치한 뒤 나머지를 채웁니다. 평가 순서는 지정배치 미충족 → 미배정 → 상한 초과 → 지정배치 교사의 자리 선호 → 일반 교사 점수 분산 → … 입니다.

## 명단 가져오기·가능 시간 정리

- 교사 명단: 텍스트 붙여넣기(가져오기 창과 ‘명단 붙여넣기’)를 없앴습니다. Google Sheets 링크 또는 엑셀·CSV 파일로만 불러옵니다. 링크는 메인 프로세스가 docs.google.com의 xlsx 내보내기 주소로만 요청하며, 시트가 ‘링크가 있는 모든 사용자’로 공유되어 있어야 합니다.
- 열 연결: 제목 행 번호를 묻지 않고 자동으로 찾습니다(없으면 모든 행을 명단으로 봄). 미리보기 표의 각 열(A열, B열…) 위 목록에서 그 열의 항목을 고릅니다. 한 항목은 한 열에만 연결됩니다.
- 교사 명단 ‘전체 삭제’ 버튼(확인 후 삭제)을 추가했습니다.
- 학급 칩: 배경 없이 학년 색 글자만, 삭제는 오른쪽 위 작은 원형 버튼입니다.
- 가능 시간: 예외만 체크합니다. 일반 교사는 체크 = 불가(빨간 ×), 지정배치 교사는 체크 = 지정 교시(파란 ✓). 기본 상태는 모두 빈 칸입니다. 저장 데이터 형식은 그대로입니다.
- 가능 시간 화면 하단에 ‘저장 및 다음 단계(감독 방식·배정 기준)’ 버튼을 추가했습니다.

## 가능 시간 두 단계 분리

교사 설정을 교사 명단 → 지정배치 교시(1단계) → 감독 불가 교시(2단계) 세 탭으로 나눴습니다. 1단계는 지정배치 계열 교사만 보이며 체크 = 반드시 감독할 교시(파란 ✓)와 배치 자리를 고릅니다. 2단계는 일반 교사만 보이며 체크 = 감독할 수 없는 교시(빨간 ×)와 불가 사유를 적습니다. 한 표 안에서 체크의 뜻이 바뀌지 않습니다. 각 단계 하단의 저장 및 다음 단계 버튼으로 이어집니다.

## 칩 정리·수정 필요·시험일정 직접 입력

- 고사실 칩: 색 대신 흰 바탕과 얇은 회색 테두리의 중립 태그(Apple Mail·미리 알림 방식)로 통일했습니다. 학년 점을 없앴고, 삭제 ×는 마우스를 올리거나 포커스했을 때만 오른쪽 위에 나타납니다.
- 교사 명단: 역할을 칩으로 표시합니다(일반 교사 회색, 나머지는 채도를 낮춘 색). 과목·담임·이동학급 칩은 무채색 테두리로 바꿔 역할 칩만 색을 가집니다.
- 가져오기: 고사실에 없는 학급·알 수 없는 역할이 있어도 불러옵니다. 해당 값은 비우거나 일반 교사로 두고 `review`에 사유를 남기며, 명단에 ‘수정 필요’ 배지를 띄웁니다. 그 칸을 고치면 해당 사유가 자동으로 지워지고, 배지를 눌러 직접 지울 수도 있습니다. 이름이 없는 행만 제외합니다.
- 시험일정: 날짜 카드는 한 줄에 3개, 넷째 날부터 다음 줄에 놓입니다. 칸에 과목을 바로 입력하고(Enter 아래 칸, Tab 옆 칸, Esc 취소), ‘전 학년’으로 같은 교시 1~3학년을 한 번에 채웁니다. 고사실마다 과목이 다를 때만 ‘고사실’ 버튼으로 기존 과목·고사실 창을 엽니다. 일부 고사실만 적용된 칸은 ‘n/m실’이 주황으로 표시됩니다.

## 직접 저장·되돌리기·반별 과목

- 자동 저장을 없앴습니다. 편집은 저장 전까지 초안이며, 상단에 ‘저장 안 됨’과 ‘저장’ 버튼(Ctrl+S)이 나타납니다. 저장하지 않고 다른 화면으로 이동하거나 앱을 닫으면 ‘저장하고 이동 / 저장하지 않고 이동 / 취소’를 묻고, 저장하지 않으면 마지막 저장 상태로 돌아갑니다. ‘저장 및 다음 단계’, 자동 배정 결과, 배정 조정 반영은 바로 저장합니다.
- 상단 ‘되돌리기 / 다시 실행’ 버튼을 글자와 함께 표시하고 Ctrl+Z, Ctrl+Shift+Z(Ctrl+Y)를 지원합니다. 입력칸 안에서는 입력칸 자체의 되돌리기가 우선합니다.
- 시험일 카드의 교시 수는 ‘3교시 [− | +]’ 스테퍼로 바꿨고 날짜 삭제는 휴지통 아이콘입니다.
- 칸에 마우스를 올리면 ‘+ 반별 과목’이 나타나 과목을 반별로 나눌 수 있습니다. 창에서 한 반은 한 과목에만 속하며, 다른 과목에서 반을 고르면 원래 과목에서 빠집니다. 새 과목은 아직 배정되지 않은 반으로 시작합니다.
- 고사실·교사 칩은 테두리 없는 회색 바탕으로 바꿨습니다.

## 방향키 입력·용어·배정 조정 간소화

- 시험일정: ‘전 학년’을 없앴습니다. 방향키로 칸을 옮깁니다(위·아래는 항상, 왼쪽·오른쪽은 글자 끝에서 또는 방금 들어온 칸에서; 같은 교시의 옆 날짜 카드로도 이어짐). 이동한 칸은 글자가 선택되어 바로 덮어 쓸 수 있습니다. 칸 도구는 ‘+ 반별 과목’과 일부 고사실 표시만 남았습니다.
- 교사 설정 탭: 교사 명단 / 특별교사 감독 설정 / 감독불가 교사 설정.
- ‘엑셀·Google Sheets 가져오기’는 고스트 버튼입니다.
- 빨간색을 #c9483f로 낮췄고, 감독불가 체크·2단계 배지·삭제 호버는 옅은 붉은 바탕으로 바꿨습니다.
- 배정표: ‘감독 교환’, ‘선택 해제’ 버튼을 없앴습니다. 같은 교시의 두 칸을 차례로 누르면 바로 교환되고, 불가하면 사유만 표시됩니다. 선택한 칸을 다시 누르면 해제됩니다. 반영 전 변경이 있을 때만 안내 줄 오른쪽에 ‘반영 전 변경 n자리 · 되돌리기 · 모두 취소 · 변경사항 반영’이 나타납니다.

## 시간표에서 불러오기 (감독불가 교사 설정)

- 컴시간알리미: 학교를 검색해 고르면 메인 프로세스가 comci.net에서 시간표를 받습니다(`electron/comcigan.ts`, pycomcigan(MIT)과 같은 방식). 컴시간은 `일자자료`에 있는 주차(보통 이번 주·다음 주)만 제공하므로, 그 주에 드는 시험일은 그 주 실제(일일) 시간표를, 그 밖의 시험일은 기본(원) 시간표를 요일 기준으로 씁니다. 목록 밖 주차를 요청하면 이번 주가 오므로 요청하지 않습니다. 학교 검색어는 내장 디코더로 만든 EUC-KR 표로 인코딩합니다.
- 엑셀 시간표: 여러 파일을 한 번에 고릅니다. 제목 행의 ‘월(19)’은 날짜 일치, ‘월’만 있으면 요일 기준으로 연결하고, 첫 열은 교시, 칸은 ‘과목\n교사’ 또는 ‘과목 교사’입니다.
- 교사 연결: 가려진 ‘김수*’는 앞 글자와 이름 길이, 약칭 ‘김수’는 앞 글자로 찾고 여러 명이면 과목(약칭 글자 순서 포함 ‘통사’⊂‘통합사회’)으로 좁힙니다. 그래도 여러 명이거나 없으면 자동으로 정하지 않고 선택하게 합니다.
- ‘고사·시험’ 과목은 수업이 아니므로 제외합니다. 적용은 일반 교사의 감독불가 체크에 더하기만 하고, 사유가 비어 있으면 ‘교과수업’을 넣습니다. 특별교사는 바꾸지 않고 알려 줍니다. 적용 뒤 저장 전까지 되돌리기로 취소할 수 있습니다.
- 사유칸 안내 문구는 첫 행에만 표시합니다.

## 버튼·탭·체크 표시 정리

- 고스트 버튼은 흰 바탕에 애플 블루 1px 테두리와 파란 글자입니다(시간표에서 불러오기, 엑셀·Google Sheets 가져오기, 배정표 되돌리기·모두 취소).
- 탭이 있는 화면(시험 설정·교사 설정)은 큰 제목을 숨기고, 번호가 붙은 밑줄 탭(① 교사 명단 ② 특별교사 감독 설정 ③ 감독불가 교사 설정)을 머리로 씁니다. 탭 설명·단계 배지는 없애고 한 줄 안내만 남겼습니다.
- 교시 체크는 SF 심볼처럼 원형입니다. 특별교사 감독 교시는 파란 체크 원, 감독불가는 붉은 빼기 원이며 칸 배경은 칠하지 않습니다.
- 시간표 불러오기에서 행마다 적용 체크(머리글에 전체 선택)를 두었습니다. 연결된 행은 처음에 선택되고, 교사를 고르면 선택되며 연결을 비우면 해제됩니다.

- 같은 가림 이름(예: 이주*)이라도 교사별로 따로 불러옵니다. 컴시간은 교사 번호, 엑셀은 이름+과목으로 구분하고, 표에서는 이름 옆에 과목을 붙여 구분합니다. 각 줄은 과목으로 따로 연결됩니다.

## 달력 선택기·엑셀 내보내기·저장 안정화

- 달력: 원본 ScheduleUI.html의 둥근 jQuery UI 날짜 선택기를 참고한 구글 캘린더식 월 달력(`src/ui/DatePicker.tsx`). 원형 날짜, 오늘은 파란 테두리, 선택은 파란 원, 이미 등록된 시험일은 점, 일·토 색 구분, ‘오늘’ 이동. 시험일 추가 창에서는 여러 날을 한 번에 골라 ‘n일 추가’하고, 날짜 카드의 날짜를 누르면 같은 달력이 팝오버로 열립니다.
- 엑셀 내보내기(배정표 ‘엑셀로 내보내기’): 원본 결과 시트를 따라 ‘교사별 전체’(교시별 고사실·사유, 날짜별 누적, 배정점수), ‘고사실별 전체’(미배정 강조, 정/부 모드 2열)와 날짜별 감독표(교사별+고사실별 / 교사별 / 고사실별, A4 가로 맞춤)를 만듭니다. 시트 데이터는 `src/domain/exportBook.ts`, 서식과 파일 쓰기는 `electron/exportXlsx.ts`.
- 감독 불가 사유 계산을 `rules.ts`의 `unavailableReason`으로 옮겨 배정표와 엑셀이 같은 규칙을 씁니다.
- 저장: Windows에서 읽는 중인 파일을 바꾸면 EPERM이 나므로, `current()`도 저장 대기열을 기다리고 이름 바꾸기는 EPERM/EBUSY/EACCES일 때 잠시 뒤 다시 시도합니다.

## 고사실 순서

원본 Code.js처럼 고사실은 학급(학년 → 반 번호, 1-1, 1-2 … 1-10) → 복도 → 특별실 순서입니다. `rules.ts`의 `compareRooms`/`sortedRooms`로 슬롯 생성, 고사실별 보기, 단독 고사실 설정, 고사실 칩·선택 창, 교사 담임·이동학급 선택, 엑셀 내보내기가 모두 같은 순서를 씁니다. 저장된 고사실 목록 자체의 순서와 ID는 바꾸지 않습니다.
