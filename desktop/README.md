# 시험감독 데스크탑

Windows용 오프라인 시험감독 배정 앱입니다. React · TypeScript · Vite · Electron으로 구성했습니다. 상위 폴더의 Apps Script 및 HTML 파일은 원본 그대로 남겨 두었습니다.

## 실행과 빌드

Node.js 22.16 이상과 npm을 사용합니다. 최초 의존성 설치와 Electron 패키징 도구 다운로드에는 인터넷이 필요하고, 빌드된 앱은 인터넷 없이 동작합니다.

```powershell
cd desktop
npm ci
npm run dev
```

```powershell
npm run typecheck
npm test
npm run build
npm start
npm run smoke
npm run package
```

- `npm run dev`: Vite 개발 서버와 Electron 앱을 함께 실행합니다.
- `npm test`: 배정 규칙, 작은 사례 전수 탐색 비교, 대규모 성능, 저장·복구 테스트입니다.
- `npm run smoke`: 실제 Electron을 별도 테스트 프로필로 실행해 입력·배정·수동 해제·실행 취소·파일 왕복·재시작·정/부 배정·계산 취소를 검증합니다. 원래 사용자의 고사는 건드리지 않습니다.
- `npm run package`: `release/ExamProctor-1.1.0-x64-Setup.exe`와 `release/win-unpacked/`를 생성합니다.
- 빌드 도구는 프로젝트의 `.builder-cache/`에 보관합니다. Windows 파일 잠금으로 NSIS 추출 폴더 교체가 실패하면 체크섬이 확인된 추출본을 복사해 패키징을 재시도합니다.
- 패키지 검증: PowerShell에서 `$env:PROCTOR_EXE = (Resolve-Path 'release/win-unpacked/시험감독.exe').Path` 지정 후 `node scripts/smoke.mjs`를 실행합니다. 검증 뒤 `Remove-Item Env:PROCTOR_EXE`로 해제합니다.

패키지는 코드서명되지 않은 로컬 배포용 빌드입니다. 배포 인증서·자동 업데이트·macOS 배포는 포함하지 않습니다.

`samples/example-exam.json`은 일반 예시, `samples/large-exam.json`은 대규모 예시입니다. 파일 가져오기로 열 수 있습니다. 검증 내역은 `VERIFICATION.md`, 배정 규칙과 기존 코드 비교는 `ALGORITHM.md`를 참고하세요.

## 사용 흐름

1. **시험일정·고사실**에서 학년별 고사실을 만든 뒤 날짜 카드의 교시×학년 칸을 클릭합니다. 선택창에서 과목과 적용 고사실을 지정하고 **적용완료**를 누릅니다. 취소하면 기존 값이 유지됩니다.
2. **교사 기본 설정** 표에서 과목·담임·이동학급 칩을 누르면 선택창이 열립니다. 과목은 복수 선택, 담임은 한 학급, 이동학급은 여러 학급을 선택합니다. 명단 붙여넣기는 이름과 과목을 탭으로 구분합니다.
3. **감독 가능 시간**은 교사별 날짜 카드의 체크박스, **제외 교시 설정**은 교사×날짜·교시 전체 표로 편집합니다. 기본은 모든 시간 가능이며 제외 교시가 우선합니다.
4. **배정 세부 설정**에서 일반/정·부 모드, 가중치·상한, 단독 감독실을 정하고 실행합니다. 같은 입력·배정안 번호(seed)·엔진 버전은 같은 결과를 만듭니다.
5. **감독 배정·조정**은 교사별 표가 기본입니다. 같은 교시의 서로 다른 교사 두 칸을 선택해 **감독 교환**을 누릅니다. 빈 교사 칸으로 옮길 수도 있습니다. 교환 가능·불가 색과 사유를 확인하세요. 고사실별 보기에서는 칸을 클릭해 교사를 직접 선택하거나 해제합니다.
6. 수동 조정은 **변경사항 반영**을 눌러 저장합니다. 그 전까지는 임시 상태이며 **조정 되돌리기**, **조정 취소**가 가능합니다. 페이지를 이동해도 임시 상태는 유지됩니다. 고사 전환·자동 배정·내보내기는 먼저 반영하거나 취소해야 합니다.
7. **고사 기록**에서 다시 열거나 JSON으로 내보냅니다. 가져온 고사는 새 ID로 복사되어 기존 고사를 덮어쓰지 않습니다.

원본 HTML 화면별 대응과 변경 이유는 `UI_REFERENCE.md`에 정리했습니다.
상단 저장 상태를 확인하세요. 입력은 약 0.65초 뒤 자동 저장되며 `Ctrl+S`로 즉시 저장할 수 있습니다. 입력이 잘못된 경우 저장 실패가 표시되고, 종료 전에도 저장을 시도합니다. 저장 실패 시 수정해서 돌아오거나 마지막 저장 상태만 남기고 닫을 수 있습니다.

## 데이터와 복구

데이터는 Electron `app.getPath('userData')/exams`에 저장됩니다. Windows에서는 `%APPDATA%` 하위의 앱 전용 폴더를 사용합니다.

- 고사별 JSON과 직전 정상본 `.json.bak`, 최근 고사를 가리키는 `current.txt`를 저장합니다.
- 저장 요청은 순서대로 처리하고 `.tmp` 파일을 쓴 뒤 교체합니다.
- 손상된 원본은 백업으로 열며 복구 알림을 표시합니다. 둘 다 손상된 기록은 손상 상태로 표시합니다.
- JSON은 `version: 1`입니다. 잘못된 날짜, 중복 ID, 존재하지 않는 교사 학급·과목 고사실 연결, 지원하지 않는 버전은 거부합니다.
- 입력 변경 시 기존 배정을 지우지 않고 ‘재검증 필요’로 표시합니다. 재검증은 사라진 자리를 정리하고 금지·중복 배정만 해제합니다. 재검증 자체는 새 자동 배정을 실행하지 않습니다.
- 자동 저장은 로컬 보호이며 외부 백업을 대신하지 않습니다. 다른 PC로 옮길 때 JSON 내보내기를 사용하세요.

## 구조

- `src/domain/`: 문서 스키마, 슬롯 생성, 금지 규칙, 독립 결과 검증, 배정 엔진
- `src/solver.worker.ts`: 취소 가능한 배정 계산 Worker
- `src/ui/`: React 화면, 한국어 UI, 로컬 CSS
- `electron/`: 파일 저장, 창 관리, 제한된 preload API
- `tests/`, `scripts/smoke.mjs`: 규칙·저장 테스트와 실제 Electron 통합 검증

renderer에는 Node.js 권한을 주지 않습니다. context isolation과 sandbox를 켜고, IPC 호출자의 창·프레임을 확인합니다. 렌더러가 파일 경로를 임의 지정하는 API나 일반 IPC 호출 API를 노출하지 않습니다. 외부 창 열기와 탐색은 차단합니다.

## 현재 범위

일반·정/부 감독, 단독 감독실, 교실·복도 가중치, 자동 배정과 검증, 수동 배정·해제·교환, 실행 취소, 로컬 기록, JSON 파일 왕복을 지원합니다.

Google Sheets 연동, 기존 Apps Script 데이터의 직접 가져오기, Excel 시간표 자동 해석, 과거 고사 점수 연계, 인쇄·PDF·Excel 내보내기는 포함하지 않습니다. 앱은 한 번에 한 인스턴스를 실행합니다. 실제 학교 데이터에 대한 최종 검토는 필요하며 알고리즘은 최적해를 증명하지 않습니다.


## 교사 명단 파일 가져오기

교사 설정 → 엑셀·Google Sheets 가져오기에서 .xlsx, .csv, .tsv를 선택합니다. Google Sheets는 파일 → 다운로드 → Microsoft Excel(.xlsx) 또는 CSV로 저장해 가져옵니다. Google 계정 직접 연결·URL 동기화는 포함하지 않습니다. 제목 행을 포함한 표를 복사해 가져오기 창에 붙여넣을 수도 있습니다.

시트와 제목 행을 선택하면 교사명·담당과목·담임·이동학급·역할·메모 열을 자동 추정합니다. 미리보기에서 열 연결을 수정한 뒤 추가하세요. 모르는 역할·등록되지 않은 학급은 해당 행을 수정하거나 제외해야 합니다. 동명이인은 경고 후 서로 다른 ID로 등록합니다. 기존 명단을 덮어쓰지 않으며, 가져오기 취소 시 변경하지 않습니다. 최대 10 MB, 2,000행·100열을 읽고 고사당 교사는 1,000명까지 등록합니다. .xls는 .xlsx로 저장해 사용하세요.

`node scripts/smoke-import.mjs`는 격리된 Electron에서 실제 XLSX 가져오기·열 선택·추가·저장과 취소를 검증합니다. 파일 대화상자만 테스트 경로로 대체합니다.
