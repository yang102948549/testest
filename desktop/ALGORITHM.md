# 배정 규칙과 기존 코드 대비 변경

## 기존 코드에서 확인한 사항

- `Code.js`는 Google Sheets와 PropertiesService를 직접 읽고 쓰며 순차적으로 교사를 선택합니다.
- 슬롯을 섞고 후보 정렬 비교마다 `Math.random()`을 호출해 같은 입력을 재현하기 어렵습니다.
- 일반 모드는 후보 부족 시 감독 횟수 제한을 완화합니다. 정/부 모드는 일반 모드의 가중치와 횟수 제한을 대부분 사용하지 않습니다.
- 수동 적합성 검사에서 동시간 중복 검사 이전에 반환하는 경로가 있고, 수동 저장 함수는 전체 제약을 다시 검사하지 않습니다.

## 1차 엔진

1. 일정으로부터 필요한 자리를 생성하고, 교사·자리별 금지 조건을 계산합니다.
2. 가능한 교사가 적은 자리부터 처리합니다. 같은 난도의 자리는 날짜·교시·ID 순으로 안정적으로 정렬합니다.
3. 후보는 필수배치, 정상 상한 준수, 누적 점수, 당일 감독 수, 역할 선호, 같은 고사실 반복, 미리 생성한 seed 난수로 비교합니다. 정렬 비교 중 난수를 생성하지 않습니다.
4. 감독자가 이미 같은 시간에 배정되어 있으면 증대 경로로 기존 교사를 다른 자리로 옮겨 충원을 시도합니다. 실패한 경로는 원상 복구합니다. 한 경로의 깊이와 방문 수를 제한합니다.
5. 정상 상한으로 배정한 뒤 빈자리에 한해 횟수 상한을 완화해 다시 시도합니다.
6. 후보의 직접 재배정·동시간 교환으로 목적함수를 개선합니다. 교환으로 금지 위반을 만들거나 기존 자리를 비우지 않습니다.
7. 작은·중간 고사는 12회, 500자리를 넘는 고사는 4회 탐색합니다. 각 회차의 개선 횟수도 고정되어 같은 입력과 seed에서 재현됩니다.
8. 독립 검증기를 통과한 결과만 반환합니다. Worker를 종료해 취소하며 이전 결과는 보존합니다.

평가 순서는 **필수배치 미충족 수 → 미배정 수 → 상한 초과량 → 일반 교사의 가중 점수 분산 → 일별 쏠림 → 역할 선호 → 고사실 반복 → 연속 감독**입니다. 금지 조건은 탐색 전제이므로 평가 점수와 교환하지 않습니다. 단일 거대 가중치로 여러 목적을 더하지 않고 사전식으로 비교합니다.

횟수 제한 완화는 사용자가 선택한 정책입니다. 최종 전체 결과에서 교사·날짜·실제 횟수·상한을 별도로 표시합니다. 필수배치 충족 및 빈자리 감소가 초과량 감소보다 우선하므로 상한 초과가 있는 결과가 선택될 수 있습니다.

## 보존한 업무 규칙

- 해당 교시의 모든 학년 시험과목 중 담당 과목이 하나라도 있으면 배정하지 않습니다. 특정 고사실 과목만 비교하지 않습니다.
- 제외 교시, 불가능 시간, 담임·이동학급, 완전 제외는 모든 모드에 적용합니다.
- 복도배치 교사는 일반 시험의 교실 및 정감독에 배정하지 않습니다. 자습 시간에는 예외를 허용합니다.
- ‘자습’은 해당 교시의 등록된 모든 과목이 자습일 때 적용합니다. 일반 모드에서는 복도 자리, 정/부 모드에서는 부감독 자리를 생성하지 않습니다.
- 정/부 모드에서는 복도 자리를 만들지 않고, 단독 감독으로 선택한 고사실에는 정감독만 생성합니다.
- 일반 모드 점수는 교실 2점·복도 1점이 기본이며 변경할 수 있습니다. 정/부 모드는 건당 1점입니다.
- 일반 모드 기본 상한은 전체 교실 6회, 하루 복도 1회입니다. ‘하루 3회 이상 허용’이 꺼져 있으면 하루 교실 2회를 기준으로 하되, 기존 코드처럼 당일 복도 감독이 있는 경우 이 일일 교실 제한에서 제외합니다.
- 필수배치는 지정된 가능 시간마다 배정을 요청하며 가능 시간을 따로 제한하지 않으면 모든 활성 시험 교시를 대상으로 합니다. 충돌하거나 자리가 없으면 미충족 경고를 남깁니다.

## 명시적으로 바꾼 부분

- 정/부 모드 슬롯에도 자습 여부를 명시해 역할 예외를 일관되게 적용합니다.
- 비고 문자열의 부분 일치로 역할을 추측하지 않고 역할을 명시적으로 선택합니다.
- 교사 이름 대신 ID로 연결하여 동명이인과 이름 변경을 지원합니다.
- 수동 배정에도 자동 배정과 같은 금지 규칙·동시간 중복 검사를 적용합니다. 두 자리 교환은 전체 결과를 하나의 변경으로 검사합니다.
- 이전 결과의 입력 서명을 보관해 입력 변경을 감지하며, 과거 결과를 현재 입력에 맞는 결과로 오인하지 않도록 표시합니다.
- 잘못된 기존 결과는 파일을 열 수는 있으나 재검증에서 드러나며, 재검증 시 유효하지 않은 연결을 해제합니다.

## 한계와 후속 검토

이 엔진은 제한된 반복 탐색이며 전체 기간의 전역 최적해나 해의 부재를 증명하지 않습니다. 가능한 후보가 남아 있는 미배정은 동시간 경쟁 또는 탐색 한도 때문일 수 있다고 표시합니다.

최적해 보장이 필요하면 현재의 문서·자리·검증 인터페이스를 유지하고 CP-SAT 기반 엔진을 추가할 수 있습니다. 교사×자리 이진 변수, 시간별 단일 배정, 금지 조건, 역할 요구, 상한 초과 변수 및 사전식 목적을 모델링할 수 있습니다. 네이티브 런타임 배포 비용과 실제 학교 사례에 대한 성능을 확인한 뒤 도입하는 편이 적절합니다.

작은 사례는 모든 가능한 배정을 열거한 최적 충원 수와 비교하며, 실제 규모는 100명·40실·5일·4교시의 합성 데이터로 검증합니다. 학교마다 필수배치·순회·자습 정책이 다를 수 있으므로 정책 변경은 명시적 설정과 회귀 테스트를 함께 추가해야 합니다.
